# Team roles

Fill in a name next to each role. One person can hold two roles if the team is small.

| Role | Who | What they own |
| --- | --- | --- |
| Science lead | | Reads the papers, checks every extracted number, writes the limitations |
| Data engineer | | Database schema, loading data, validation, export |
| Backend / SI engineer | | Ranking and gap code, search, the assistant |
| Frontend engineer | | Coverage Map, matrix, compare screen, scenario screen |
| Storyteller / designer | | Pitch, demo script, look and feel |

## Scope freeze (decided in Phase 0)

Tier 1 is the MVP: Coverage Map, Scenario Lab, Ranking, Explorer, Compare and the cited assistant.
Everything else (Tier 2, Tier 3, role views) is optional. We only start it once Tier 1 works.
